# E-commerce Sales & Customer Behavior Analysis (PostgreSQL)

## О проекте
Проект направлен на решение прикладных задач продуктовой и коммерческой аналитики интернет-магазина:
- Оценка помесячной динамики выручки и темпов роста (MoM Revenue Growth).
- Расчет среднего времени возврата клиентов за повторной покупкой.
- Анализ товарных направлений: расчет вклада категорий в общую выручку и их ранжирование.

## Стек технологий
PostgreSQL, CTE (Common Table Expressions), Window Functions (`LAG`, `LEAD`, `ROW_NUMBER`, `DENSE_RANK`, `SUM() OVER ()`), Aggregations (`GROUP BY`, `HAVING`).

## Ключевые аналитические задачи

### 1. Ежемесячные темпы роста выручки (MoM)
- Выручка агрегируется по месяцам на основе успешно доставленных заказов (`status = 'delivered'`).
- Прирост месяц-к-месяцу рассчитывается с помощью функции `LAG()`:
  $$\text{growth\_pct} = \frac{\text{revenue} - \text{prev\_revenue}}{\text{prev\_revenue}} \times 100$$

### 2. Время до совершения повторного заказа
- Заказы каждого пользователя нумеруются хронологически (`ROW_NUMBER()`).
- С помощью `LEAD()` рассчитывается разница в днях между первой и второй покупкой для когорты вернувшихся клиентов.
- Находится средний интервал возврата для оптимизации триггерных маркетинговых цепочек.

### 3. Структура ассортимента и доли категорий в обороте
- Расчет суммарной выручки по направлениям товаров.
- Вычисление процентной доли каждой категории от валового оборота через оконную функцию `SUM() OVER ()`.
- Ранжирование категорий по прибыльности (`DENSE_RANK()`).
